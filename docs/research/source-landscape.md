# source landscape for 2021–2024

Checked 2026-09-23. This is a source inventory for two connected but distinct analyses: (1) dated company and product positioning, and (2) public-market performance and activity. “Free” means public access without a data subscription; it does not mean complete, verified, or cheap to process at arbitrary scale. Some free endpoints still require an account and key, and access does not grant public redistribution rights.

## Recommendation

Keep two evidence streams explicit. For company and product positioning, use Internet Archive captures first for a small reviewed company list, Common Crawl to broaden discovery and coverage, and SEC EDGAR/Form D for dated reported financial and financing facts. For public-market analysis, Cboe provides a verified market-wide daily activity series; NasdaqTrader adds anonymous monthly volume statistics by symbol; Alpaca's multi-symbol historical stock-bars API is a candidate for daily per-security OHLCV from the SIP feed. These records have different units and provenance from company statements, so store them separately and retain observation, trade, filing, and capture dates as applicable.

Neither web archive is a census of company sites. SEC filings cover regulated disclosures, not private-company operating metrics or daily share prices. Alpaca documents a free tier and delayed historical SIP access, but entitlement to 2021–2024 records and rights for any public reuse are not verified for an account. NasdaqTrader's downloadable statistics do not provide per-symbol OHLCV. Private-company fundamentals and permission to redistribute market data remain gaps.

## Bounded live probes

These are endpoint observations from this review, not service guarantees:

- Wayback Availability returned HTTP 200 for `www.getdbt.com` at `20211201`, with the closest snapshot `20211201100435` and an archived URL. A narrow CDX query returned timestamped 2021 HTML records with status, digest, and byte length.
- Common Crawl’s collection list included `CC-MAIN-2021-49` (2021-11-26 through 2021-12-09) and `CC-MAIN-2024-51` (2024-12-01 through 2024-12-15). A two-record lookup for `www.getdbt.com/` returned 2021 HTML captures; the 2024 lookup returned a 308 redirect and a 200 HTML record with WARC location fields. This confirms index discoverability for this host in those two collections, not corpus-wide recall or successful WARC-body retrieval.
- SEC’s submissions endpoint for Confluent CIK `0001699838` returned HTTP 200 JSON with the company name and SIC classification. This is a basic access check, not validation of historical XBRL completeness.
- NasdaqTrader’s daily market file endpoint returned HTTP 200 without authentication. The December 2021 and December 2024 symbol-volume XLSX links also returned HTTP 200 without credentials. This verifies anonymous file access for these samples; NasdaqTrader's stated use restriction still applies. The daily file list exposed the current YTD file, not historical 2021–2024 daily files.
- The Cboe historical page lists annual CSVs for every study year. The separate [bounded pilot](../pilot-results.md) downloaded and schema-checked all four files: 4,788 rows/252 days (2021), 4,769/251 (2022), 4,750/250 (2023), and 4,786/252 (2024). Cboe requests attribution as **Cboe Exchange, Inc.** in published reports.
- Alpaca documentation describes the free Basic plan, API key authentication, multi-symbol bars, 200 requests/minute, and historical SIP access for requests ending at least 15 minutes in the past. No authenticated Alpaca account was used, so 2021–2024 access and account-specific permissions remain unverified.

An earlier query to the Common Crawl index timed out/returned HTTP 502, then the narrower requests above succeeded. A first broad Wayback CDX query timed out; the date-bounded URL query and Availability endpoint succeeded. Treat transient index failures as expected ingestion outcomes and retain attempts, as the current project design does.

## Practical next step

For the next research slice, keep the existing manually reviewed URL list and capture model for company/product positioning. Compare Wayback and Common Crawl coverage at the target cutoffs and record whether fetched bodies are usable. Add SEC filing metadata only for reliable CIK matches. For public-market analysis, make a short account-backed Alpaca check for a few 2021–2024 SIP bars before relying on the published tier summary; keep market bars, NasdaqTrader volume reports, and company evidence in separate tables. Do not publish Alpaca market data or use NasdaqTrader symbol statistics for commercial/academic purposes without the required permissions. Do not use current directory descriptions to backfill historical attributes without dated primary evidence.
