# temporal graph legibility

Focused company neighborhoods open at 140% of the previous fitted scale. This is a presentation zoom over the same deterministic anchors, so positions remain stable through time and distances still carry no evidence meaning. The map remains pannable, and reset restores this focused view.

Direct focus-to-neighbor connections remain visible by default. Peer context connections are off by default in a focused neighborhood and can be enabled under **view settings**. The overview retains its quiet context field. This keeps dense company neighborhoods readable without removing evidence or changing the server frame.
